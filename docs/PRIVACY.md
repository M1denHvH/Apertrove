# Privacy

Apertrove stores settings, library records, sessions, and previews in the local user profile. It writes captured originals to the selected session output or camera destination. Original photographs can include EXIF and other metadata. Keep that in mind when exporting images or sharing diagnostic information.

Web Remote is opt-in. It serves camera state, previews and controls over HTTP and WebSocket on the selected interface. Its key authorizes the device that has it. Use it on a trusted local network and keep the QR link private. Stop the server to revoke the active key. [Security](../SECURITY.md)

Equipment cards can request product information and images from official manufacturer sites and cache the results locally. Such requests expose ordinary web request information to those sites. Their images retain the manufacturers’ rights. Opening an official vendor link uses your default browser.

This build has no account or product analytics integration. Canon software installed separately follows Canon’s own policies.
