

Проверка 13 ноября 2026 года. Windows x64, Electron и Koffi. Рабочий компьютер предоставил EDSDK.dll 3.18.40.0 из Canon Picture Style Editor. Это версия файла Windows. Она не гарантирует точное соответствие номеру пакета из таблицы Canon. Библиотека загрузилась, обязательные экспорты разрешились, `EdsInitializeSDK` и `EdsGetCameraList` прошли. Повторная инициализация без открытой камеры прошла. SDK вернул 0 камер. Состояния камеры ниже проверены с тестовыми данными, если явно не указано иное.

Публичные материалы Canon описывают совместимость и изменения SDK. Полный справочник и заголовки поставляются с пакетом для разработчиков. Точный пакет с документацией для установленной DLL на этом компьютере отсутствовал. Для ABI `EdsVolumeInfo` использован опубликованный Canon API Programming Reference, раздел 3.1.10. Доступность новых API проверяется по экспортам самой DLL. Наличие экспорта не считается доказательством поддержки камерой.

## Новые привязки

- `EdsGetVolumeInfo(EdsVolumeRef, EdsVolumeInfo*)` — опциональный API чтения тома; H1-диагностика намеренно его пропускает до подтверждения layout `EdsVolumeInfo`.
- `EdsGetPropertySize`, `EdsGetPropertyData` и `EdsGetPropertyDesc` уже были привязаны. Добавлены чтение диагностических свойств и `kEdsPropID_MeteringMode` в существующую цепочку управления.
- Для диагностики среды читается PE-заголовок, разрешаются обязательные функции и выполняется реальная инициализация. Если кандидат не загрузился, проверяется следующий. Версия читается из ресурса файла Windows. Установка Canon выполняется пользователем по официальной ссылке.

## Границы проверки

Диагностическая сессия открывается по запросу и читает свойства. Настройка назначения передачи выполняется после явного подключения. Уже работающий Live View использует тот же worker. Busy и неподтверждённые команды отличаются от документированных ограничений моделей с импортом. Аппаратные сценарии после обновления требуют подключённой камеры: проверка открытия сессии, чтение томов, смена замера и назначения, отключение и переподключение USB, получение кадра. Результаты старых аппаратных проверок других версий не заменяют эту проверку.
