# Продолжение разработки на другом компьютере

Снимок проекта: **Apertrove 0.8.1**, 29 октября 2026 года. Это архив исходников для переноса разработки. Публикация на GitHub отложена по решению владельца; ничего не опубликовано.

## Запуск

1. Распакуйте весь архив в обычную локальную папку и откройте папку `Apertrove` в редакторе.
2. Установите Node.js 24 x64 с npm. Для установки зависимостей нужен интернет.
3. В PowerShell из корня проекта выполните:

```powershell
npm ci
npm test
npm run build
npm start
```

В архиве есть `package-lock.json`, фиксирующий версии зависимостей. `node_modules` устанавливается через `npm ci`; готовые сборки, временные профили и результаты проверок не включены.

Для разработки интерфейса запустите `npm run dev`. Во втором окне PowerShell из корня проекта:

```powershell
$env:FOCAL_DEV_URL = 'http://127.0.0.1:5173'
npm start
```

После работы с сервером разработки удалите переменную в этом окне, прежде чем запускать собранный интерфейс:

```powershell
Remove-Item Env:FOCAL_DEV_URL -ErrorAction SilentlyContinue
```

`npm run package` создаёт локальную Windows-сборку в `release/win-unpacked`; публикацию не выполняет.

## Подключение камеры

Для сборки и модульных тестов камера и SDK не нужны. Для управления камерой отдельно установите официальный Canon EDSDK x64 или совместимое официальное ПО Canon. Приложение ищет `EDSDK.dll` в известных каталогах Canon; также можно указать каталог в настройках или через `EDSDK_DIR`. Проприетарные файлы SDK в архив не входят.

Для EOS 2000D используйте USB, отключите Wi-Fi камеры и закройте EOS Utility. Объектив для автофокуса должен быть в AF. Физически проверена EOS 2000D; возможности других камер определяются SDK и самой камерой.

Для веб-пульта выберите сетевой интерфейс на новом компьютере и включите сервер заново. Правило брандмауэра привязано к компьютеру и пути EXE; инструкция и помощник находятся в README и `scripts/Allow-LanRemote.ps1`. Старые QR-ссылки не переносятся.

## Текущее состояние

- Три оформления: Studio, Canon Classic и Modern; светлая, тёмная и системная темы, свой акцентный цвет.
- Веб-пульт синхронизирует оформление, тему и акцент с приложением; адаптивная вёрстка проверена на мобильных и настольных размерах.
- Сессии с отдельными папками и очередями пресетов, удаление сессии с выбором сохранения фотографий.
- Live View, точки AF, автофокус без Live View, опция «Получить кадр при успешном фокусе», режимы и параметры съёмки, формат RAW/JPEG, композиционные направляющие и редактор панелей.
- Подъём встроенной вспышки использует Windows WIA/PTP с временным освобождением и восстановлением соединения SDK. Прямая публичная команда подъёма вспышки EDSDK в текущей реализации не используется.
- В версии 0.8.1 добавлено удаление фото с карточки, из просмотра и группой; Ctrl+A выбирает видимые фото, Delete открывает подтверждение. Оригиналы перемещаются в корзину Windows. Общие файлы других записей защищены, ошибки допускают повторную попытку, сами сессии сохраняются.
- Метаданные, рейтинги, неразрушающие правки, импорт, карточки оборудования и пресеты находятся в исходниках и описаны в документации.

Последняя проверка версии 0.8.1: 83 модульных теста, проверки удаления фото в исходной и собранной версии с тестовыми файлами и настоящей корзиной Windows, регрессионные проверки сессий и студийного интерфейса. Пользовательская библиотека при обновлении была сохранена. На новом компьютере проверки следует выполнить заново.

## Проверки без камеры

```powershell
npm test
npm run build
npm run preflight
node tests/photo-delete-ui.cjs
node tests/session-delete-ui.cjs
node tests/studio-ui.cjs
node tests/remote-appearance-ui.cjs
node tests/remote-layout-audit.cjs
```

UI-проверки создают временные данные и результаты в `qa/`. Если Playwright запросит браузер для браузерных проверок, установите его командой `npx playwright install chromium`.

Не запускайте аппаратные тесты автоматически. Они могут изменять параметры камеры, двигать объектив или делать снимки в зависимости от скрипта и флагов. Новые реальные снимки требуют отдельного разрешения владельца; ранее согласованные лимиты не являются разрешением для следующих проверок.

## Данные пользователя

Архив содержит только проект. Локальная библиотека, фотографии, кэши, настройки и ключи веб-пульта не включены. При отдельном переносе библиотеки нужно скопировать не только `library.json`, но и оригиналы фотографий; в библиотеке и сессиях сохранены абсолютные пути.

Приложение использует `%APPDATA%\Apertrove`, а при наличии старой библиотеки — `%APPDATA%\Focal Studio`. Существующие папки фотографий автоматически не перемещаются. Для чистой разработки можно использовать отдельный профиль:

```powershell
$env:FOCAL_TEST_DATA = Join-Path (Get-Location) 'qa\manual-profile'
npm start
```
